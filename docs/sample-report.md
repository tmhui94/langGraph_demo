# Sample Recruitment Sourcing Report

## Scenario

Software Engineer - Kajang / Selangor, Malaysia

## Required Candidate Information

Minimum 3 years of software development experience, C#, .NET, React or Angular,
SQL Server, REST APIs, Docker, microservices (preferred), Azure (preferred),
CI/CD (preferred), and IoT integration (preferred).

## Live-Result Rule

Candidate names, profiles, skills, scores, and sources are generated only from permitted
provider responses and source-backed evidence. With no configured search credentials,
the report returns an explicit provider limitation and zero live candidates.

## Report Sections

1. Job description summary
2. Search strategy and provider limitations
3. Candidate discovery count
4. Evaluated count
5. HIGH / MEDIUM / LOW distribution
6. Top 10 ranking
7. Individual evidence profiles
8. Comparison and skills gaps
9. Source links and retrieval timestamps
10. Human recruiter follow-up recommendations
